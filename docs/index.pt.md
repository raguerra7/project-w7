## Contexto

A W7 é um ecossistema criado para projetar, construir e evoluir iniciativas significativas. O GitHub é sua fonte oficial de verdade; este site é gerado diretamente do Markdown versionado no repositório.

Comece pela [Constituição](foundations/constitution.md). Ela é o documento do qual todo o restante do ecossistema herda seus princípios.
