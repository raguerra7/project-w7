# Modelo Operacional da W7

Version: 1.0.0

Status: Active

Owner: Rafael da Silva Guerra

## Propósito

Este documento explica como a W7 transforma seus Fundamentos em iniciativas governadas e resultados úteis.

---

## Contexto

A W7 é um ecossistema e um modelo operacional, não uma promessa de adotar uma única forma jurídica ou modelo de negócio. Uma sequência compartilhada mantém o trabalho coerente sem centralizar todas as decisões das iniciativas.

---

## O Modelo

```text
Fundamentos → Identidade → Governança → Framework → Iniciativas → Produtos → Experiências
```

Cada camada herda as restrições das camadas à sua esquerda. Uma camada posterior pode especializá-las, mas não contradizê-las.

| Camada | Pergunta | Local canônico |
|---|---|---|
| Fundamentos | Por que existimos e como nos comportamos? | `docs/foundations/` |
| Identidade | Como o pertencimento à W7 é expresso? | `docs/identity/` |
| Governança | Quem decide e como mudanças são aprovadas? | `docs/framework/governance.md` |
| Framework | Como decisões, iniciativas e produtos são criados? | `docs/framework/` |
| Iniciativas | Quais áreas duradouras de trabalho existem? | `docs/initiatives/` |
| Produtos | Quais resultados mantidos uma iniciativa possui? | Repositório da iniciativa |
| Experiências | Como as pessoas encontram esses resultados? | Repositório do produto ou iniciativa |

## Ciclo Operacional

1. **Capturar:** reunir observações e ideias; notas pessoais podem começar no Rafael OS, sem autoridade oficial.
2. **Esclarecer:** definir propósito, beneficiário, limites, evidências e valor esperado.
3. **Decidir:** classificar a decisão e registrar um ADR quando necessário.
4. **Construir:** criar o menor resultado útil sob os padrões aplicáveis.
5. **Validar:** revisar correção, consistência, segurança, usabilidade e documentação.
6. **Publicar:** registrar o resultado canônico no repositório GitHub responsável.
7. **Aprender:** observar os resultados e alimentar o próximo ciclo com evidências.

## Fonte de Verdade

Os repositórios GitHub mantêm o registro oficial da W7. Rafael OS limita-se à gestão pessoal de conhecimento e captura inicial; algo só se torna oficial após revisão e commit.
