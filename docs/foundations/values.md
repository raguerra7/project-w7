## Purpose

This document defines the values used to judge how W7 works, especially when several valid paths are available.

---

## Context

Values are behavioral commitments, not promotional words. Each value below includes the observable behavior expected from W7 and its initiatives.

---

## Values

### Curiosity

We ask before assuming, test before declaring, and remain willing to revise a belief when evidence changes.

### Clarity

We turn complexity into explanations, decisions, and systems that others can understand and maintain.

### Craft

We care about correctness, usability, and the details that make work durable. We improve through deliberate iteration rather than chasing perfection before learning.

### Generosity

We share knowledge that can help others, credit the work we build upon, and create conditions in which people can grow.

### Responsibility

We accept ownership for decisions and outcomes. Human judgment remains accountable even when tools, automation, or AI contribute.

### Continuity

We build for a future reader and maintainer. Open formats, documented reasoning, and transferable knowledge matter more than short-lived convenience.

### Joy in the Journey

We value the process and the people who share it, not only the destination. Sustainable pace, relationships, and learning are part of success.

## Using the Values

When values appear to conflict, the Constitution and Information Boundaries take precedence. The Decision Framework records the trade-off instead of pretending it did not exist.
